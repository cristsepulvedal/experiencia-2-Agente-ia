# ⚖️ Sistema de Liquidación de Siniestros - RAG & Agentes IA

Plataforma corporativa desarrollada para la **Evaluación Parcial N°1** (Ingeniería de Soluciones con IA - Duoc UC)[cite: 2]. El sistema implementa un flujo **RAG (Retrieval-Augmented Generation)** utilizando LangChain, base de datos vectorial FAISS, embeddings de Google y el modelo `gemini-1.5-flash` con interfaz en Streamlit.

## 🚀 Instrucciones de Ejecución

1. Clona o descarga este repositorio en tu equipo local.
2. Asegúrate de tener Python instalado y ejecuta los siguientes comandos en tu terminal para instalar dependencias:
   ```bash
   pip install streamlit langchain-google-genai langchain-community faiss-cpu
